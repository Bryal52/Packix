# Packix — план

Архиватор для macOS (потом Windows, потом Android). Работает в фоне, значок только в строке меню / трее.
Движок — 7-Zip (`7zz` / `7z.exe`), обёрнутый в своё ядро. Стек: C++20 + Qt 6.

## Решения

### Общее
- Отдельное приложение. Позже встраивается в Folix (другой проект): Folix подключает `core` + `dialogs`.
- Никакого хардкода: тексты, цвета, форматы, уровни сжатия, типы файлов — в `shared/*.json`.
- Ядро — чистый C++/QtCore без GUI и без системного кода. Системное — за интерфейсами в `platform/`.
- Движок за интерфейсом `Engine`: сейчас процесс `7zz`, для Android — 7-Zip как библиотека.
- Пароли передаются 7zz через stdin, не в командной строке.
- Пока только macOS. Windows — позже (код сразу кроссплатформенный). На GitHub не публикуем, только локальный git.
- Xcode нет → интеграция с «Командами»/Spotlight отложена.

### Поведение
- Без Dock (LSUIElement), значок в строке меню. Окна — только по делу; пока окно открыто, оно в ⌘Tab.
- Первый запуск: [✓] архиватор по умолчанию, [✓] запускать при входе.
- Двойной клик по архиву → окно с содержимым (дерево).
- Правый клик по файлам в Finder → «Архивировать» (Службы macOS).
- Параллельные операции без ограничений.

### Окно архива
- Кнопки: Распаковать, Удалить из архива, Поставить пароль (+ Сменить/Снять). Поиск ⌘F.
- Список как в Folix (иконки типов, папки сначала, серые второстепенные колонки) + стрелки дерева, колонка «Сжато», книжка с замочком у зашифрованных.
- Вытащить мышкой → распаковать туда. Затащить → добавить в архив.
- Двойной клик по файлу → открыть из временной папки; изменён → «Обновить в архиве?».
- Вложенный архив → новое окно «Внешний.zip › Внутренний.7z».
- Многотомные (.001, .partN.rar, .r00, .z01): любую часть открывает как целое, недостающую часть называет заранее.
- «Удалить» недоступно для rar/iso/dmg (с подсказкой).
- «Поставить пароль»: распаковать во временную → упаковать с паролем → проверить → заменить. RAR → спросить zip или 7z.
- Зашифрованные имена → по центру книжка с замочком + поле пароля.
- Горячие клавиши: ⌘A, ⌫, ⌘E, ⌘F, Esc.
- Справа внизу — кнопка логов (как в Folix).

### Окно «Архивировать»
```
Имя:     [            ]     ← пишет пользователь, пустое
Тип:     [ zip ▾ ]          ← zip, 7z, tar.gz, tar.xz; всегда zip по умолчанию
Сжатие:  [ Обычное ▾ ] (?)  ← Без сжатия / Быстрое / Обычное / Максимальное; всегда Обычное
Пароль / Подтвердите        ← только для zip; при смене типа поля исчезают и стираются
Куда:    [ текущая папка ] [⋯]
                 [ Отмена ] [ Создать ]
```
- Не совпадают пароли → «Создать» неактивна.
- Enter = Создать, Esc = Отмена. Ничего не запоминаем.
- zip всегда Deflate (открывается везде), 7z — LZMA2 solid.

### Окно распаковки
- Поле адреса + быстрые папки как в Folix + «Рядом с архивом» + «Обзор…», галочка «Создать папку с именем архива».

### Если файл существует
- «Вы уверены, что хотите заменить? Заменённый файл нельзя вернуть.» — [Отмена] [Оставить оба] [Заменить], по умолчанию Отмена.
- «Оставить оба» → «Имя (1).zip», «Имя (2).zip»…
- При распаковке + «Применить ко всем».

### Пароли
- Окно пароля с галочкой «Запомнить» (Связка ключей). Список частых паролей пробуется автоматически.
- Неверный → тряска поля и книжки, поле очищается.

### Безопасность
- Защита от `../`, абсолютных путей, опасных симлинков, zip-бомб.
- Проверка места до распаковки.
- Наследование quarantine (macOS) / Mark-of-the-Web (Windows).
- Временные файлы в закрытой папке, чистка при закрытии и при следующем запуске.
- Без мусора macOS в архивах (.DS_Store, __MACOSX, ._*).

### Дизайн
- Палитра — мягкий красный (Folix синий). Значения в `shared/theme.json`.
- Иконка книжки с замочком (заперта / открыта, щелчок застёжки).
- Прогресс — «ртутный градусник»: стеклянная трубка, жидкость с волной, плавное догоняние.
- Анимация упаковки ~250 мс, ease-out, не блокирует.
- Светящаяся зона «Перетащите сюда».
- Свои иконки архивов в Finder (ZIP/7Z/RAR/TAR).
- Уведомление о готовности (только macOS), если операция > ~10 с.
- Все анимации 150–250 мс, учитывают «Уменьшить движение».

### Настройки
- Язык (иконка глобуса, путь к JSON, «Показать в Finder», «Скопировать путь»), автозапуск, по умолчанию, сохранённые пароли.
- Языки: `lang/*.json` встроенные + `~/Library/Application Support/Packix/lang/`, формы множественного числа, запасной — ru.

### По умолчанию открываем
zip, 7z, rar, tar, gz, tgz, bz2, xz, zst, многотомные. Не трогаем apk/vpk/jar/ipa/docx/epub/iso/dmg/pkg.

## Структура
```
core/      ядро: Engine, Archive, операции, безопасность, многотомные (без GUI)
shared/    theme.json, lang/, formats.json, compression.json, file-types.json, icons/
platform/  macos/ (windows/, android/ потом)
dialogs/   общие окна (для Packix и Folix)
app/       трей, окно архива, настройки, интеграция
cli/       консольная утилита
tests/
```

## Этапы
1. core + cli: список, распаковка, пароли, создание, удаление, тесты.
2. shared-данные, локализация, тема, лог.
3. dialogs: Архивировать, Распаковать, Пароль, Файл существует, Прогресс-градусник.
4. app: окно архива, трей, настройки, первый запуск.
5. macOS: Info.plist (типы, LSUIElement), Службы, автозапуск, по умолчанию, уведомления, quarantine.
6. Сборка: build.sh → /Applications/Packix.app, иконка (ждём от пользователя).
7. Потом: Windows, Команды (нужен Xcode), Folix, Android.
